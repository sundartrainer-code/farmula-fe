# Formula Frontend

Formula is an online learning platform focused on:

- Public Speaking
- Spoken English
- Personality Development
- Leadership Development
- Communication Skills
- US Visa Coaching
- Study Abroad Preparation

## Tech Stack

- Vue 3
- Vite
- Pinia
- Vue Router
- TailwindCSS

## Run Locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```
